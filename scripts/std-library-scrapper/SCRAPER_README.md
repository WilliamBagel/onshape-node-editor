# FeatureScript Documentation Scraper

This tool scrapes the Onshape FeatureScript library documentation from [https://cad.onshape.com/FsDoc/library.html](https://cad.onshape.com/FsDoc/library.html) and converts it to JSON format.

Generated by Claude Haiku 4.5

## Scripts

**`scrapeFeatureScriptDocs.mjs`** - Basic static HTML parser
- Lightweight, fast
- Works for statically-rendered content
- Requires: `cheerio`

**`scrapeFeatureScriptDocs-advanced.mjs`** - Advanced parser with fallback to dynamic rendering
- Intelligently tries static fetch first
- Falls back to Puppeteer for dynamic content
- Supports `--browser` flag to force Puppeteer
- Requires: `cheerio`, optionally `puppeteer`

## Installation

### Option 1: Basic Setup (Recommended)
```bash
pnpm install --save-dev cheerio
```

Then run:
```bash
node scripts/scrapeFeatureScriptDocs.mjs
```

### Option 2: Full Setup (For Dynamic Content)
```bash
pnpm install --save-dev cheerio puppeteer
```

Then run:
```bash
# Try static fetch first, fallback to Puppeteer if needed
node scripts/scrapeFeatureScriptDocs-advanced.mjs

# Force usage of Puppeteer (for heavy JavaScript rendering)
node scripts/scrapeFeatureScriptDocs-advanced.mjs --browser
```

## Fields Extracted

- **fs-categories**: Top-level organization categories
- **file headers**: Section names and descriptions
- **function/node signatures**: Complete function/node declarations
- **descriptions**: Documentation text for each item
- **parameter tables**: Name, type, and description for each parameter
- **return types**: Extracted from signatures

## Adding to package.json

Add these scripts to `package.json` for convenience:

```json
{
  "scripts": {
    "scrape:docs": "node scripts/scrapeFeatureScriptDocs.mjs",
    "scrape:docs-advanced": "node scripts/scrapeFeatureScriptDocs-advanced.mjs",
    "scrape:docs-browser": "node scripts/scrapeFeatureScriptDocs-advanced.mjs --browser",
    "organize:docs": "node scripts/organizeLibrary.mjs",
    "scrape:all": "npm run scrape:docs && npm run organize:docs"
  }
}
```

Then run:
```bash
pnpm scrape:docs              # Basic scraping
pnpm scrape:docs-advanced     # Advanced scraping with fallback
pnpm scrape:docs-browser      # Force browser rendering
pnpm organize:docs            # Deduplicate & organize (run after scrape)
pnpm scrape:all               # Complete pipeline: scrape + organize
```

**Note:** These are already added to the project's package.json

## Troubleshooting

**"cheerio not found"** error:
```bash
pnpm install --save-dev cheerio
```

**"Content too small" or incomplete data**:
Use the advanced script with browser support:
```bash
pnpm install --save-dev puppeteer
node scripts/scrapeFeatureScriptDocs-advanced.mjs --browser
```

**Module import errors**:
Verify `"type": "module"` is set in package.json (already present in this project)

## Data Organization Pipeline

After scraping, the `organizeLibrary.mjs` script:

1. **Deduplicates entries** - Merges multiple versions of the same function, keeping the one with more parameters
2. **Accumulates types** - Groups entries by descriptor type (function, enum, predicate, const, type)
3. **Creates indexes** - Builds searchable indexes by type, category, and name
4. **Tracks locations** - Records which file and category each entry came from

### Results (Actual Data):
- **Original:** 1400 entries across 211 files in 5 categories
- **After dedup:** 1189 unique entries (211 duplicates removed, 15%)
- **Overloaded functions:** 119 functions had 2-4 variants that were consolidated

### Output Structure:
```json
{
  "entries": [ ... ],        // All deduplicated entries
  "byType": { ... },         // Index by descriptor type
  "byCategory": { ... },     // Index by category  
  "byName": { ... },         // Index by function name
  "metadata": { ... }        // Statistics and counts
}
```

For detailed information about the organization process and output structure, see [ORGANIZATION_README.md](ORGANIZATION_README.md).
